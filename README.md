# 💰 IncomeLab - Panduan Buat Duit Online

Laman web penyelidikan komprehensif tentang cara menjana pendapatan online dengan strategi yang telah diuji dan terbukti berkesan.

## ✨ Ciri-ciri Utama

- 🎯 **9 Kaedah Pendapatan** - Dari freelancing hingga SaaS
- 🧮 **Kalkulator Pendapatan** - Kira potensi earnings anda
- 🏆 **Kisah Kejayaan** - Contoh realiti orang berjaya
- 🗺️ **Peta Jalan Visual** - Timeline $0 ke $10,000/bulan
- 💸 **100% Free Marketing** - 10 cara percuma tarik pengunjung
- 💰 **Getting Paid** - Cara duit masuk akaun bank
- 🎯 **Interactive Quiz** - Cari method terbaik untuk anda
- 📊 **Comparison Table** - Bandingkan semua methods

## 🛠️ Tech Stack

- **React** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Vite** - Build tool

## 🚀 Cara Guna

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build untuk production
npm run build

# Preview production build
npm run preview
```

## 📱 Responsive Design

Laman web ini fully responsive dan berfungsi di semua devices - mobile, tablet, dan desktop.

## 🌙 Dark Mode Support

Sokongan dark mode built-in untuk pengalaman viewing yang lebih selesa.
